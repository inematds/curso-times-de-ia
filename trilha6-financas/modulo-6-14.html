Objetivo

Compilar todas as análises em markdown dos arquivos FINANCE-*.md no diretório de trabalho atual em um único PDF polido, que um consultor, familiar ou parceiro de responsabilização possa ler de ponta a ponta.

Quando Acionar

  • O usuário digita /finance report-pdf ou /finance pdf
  • O usuário pede "criar um relatório em PDF", "me dê um documento pronto para o cliente", "exportar meu plano financeiro"
  • Após executar /finance analyze (sugerir isso como o próximo passo natural)

Pré-requisitos

Antes de gerar, certifique-se de que o usuário possui pelo menos um arquivo de análise no diretório de trabalho atual:

  • FINANCE-ANALYSIS.md (de /finance analyze) — entrada principal
  • FINANCE-BUDGET.md
  • FINANCE-DEBT.md
  • FINANCE-RETIREMENT.md
  • FINANCE-PORTFOLIO.md
  • FINANCE-EMERGENCY.md
  • FINANCE-NETWORTH.md
  • FINANCE-GOALS.md
  • FINANCE-COMPARE.md
  • FINANCE-SCREEN.md
  • FINANCE-FIRE.md
  • FINANCE-TAXES.md

Se nenhum arquivo for encontrado, solicite ao usuário que execute primeiro /finance analyze ou /finance quick.

Processo

Etapa 1: Varredura de Arquivos de Origem

ls FINANCE-*.md

Leia todos os arquivos encontrados. O script gerador em Python também realiza sua própria varredura; o assistente lê previamente para validar a qualidade do conteúdo e identificar lacunas óbvias antes da geração.

Etapa 2: Extração de Dados

Obtenha dos arquivos markdown:

  • Pontuação Composta de Saúde Financeira (0-100) e nota em letra
  • Sub-pontuações para cada uma das 5 categorias (Fluxo de Caixa, Dívida, Investimentos, Aposentadoria, Proteção)
  • Pontos-chave de dados financeiros:
  • Renda / despesas / excedente mensal
  • Taxa de poupança
  • Patrimônio líquido
  • Dívida total e DTI (Dívida sobre Renda)
  • Meses cobertos pelo fundo de emergência
  • Saldo projetado de aposentadoria vs. necessário
  • Alocação de ativos
  • Itens de ação (classificados por prioridade)
  • Nome do usuário / nome do agregado familiar (se fornecido)
  • Data de geração

Etapa 3: Executar o Gerador de PDF

Execute:

Bash(python3 ~/.claude/skills/finance/scripts/generate_finance_pdf.py)

O script lê todos os arquivos FINANCE-*.md do diretório de trabalho atual, analisa as seções estruturadas e monta um PDF usando ReportLab.

Se o script estiver ausente ou apresentar erros, faça uma queda graciosa para um relatório consolidado apenas em markdown nomeado FINANCE-PLAN.md e informe o usuário.

Etapa 4: Confirmar Saída

Após a geração:

  1. Verifique se FINANCE-PLAN.pdf existe no diretório de trabalho atual
  2. Relate o tamanho do arquivo e o número de páginas ao usuário
  3. Sugira compartilhá-lo com seu consultor financeiro / contador (CPA)

Estrutura do PDF

O gerador produz as seguintes seções:

Página de Capa

  • Título: "Plano Financeiro Pessoal"
  • Nome do usuário / agregado familiar
  • Data
  • Medidor de Pontuação Composta de Saúde Financeira (visual de 0-100)
  • Nota em letra (A+ a F)
  • Sinal de uma linha ("Excelente — apenas otimizações menores")
  • Rodapé com aviso legal

Página 2: Resumo Executivo

  • Top 3 pontos fortes
  • Top 3 lacunas prioritárias
  • Foco deste trimestre (uma única frase)
  • Tabela de números-chave:
  • Patrimônio líquido
  • Excedente mensal
  • Taxa de poupança
  • DTI
  • Meses de emergência

Página 3: Detalhamento da Pontuação de Saúde Financeira

  • Gráfico de barras das pontuações das 5 categorias
  • Cada categoria: pontuação / peso / o que mede / sinal

Página 4: Fluxo de Caixa e Orçamento

  • Gráfico de Renda vs. Despesas
  • Top 5 categorias de despesas
  • Tendência do excedente
  • Ajustes de orçamento recomendados

Página 5: Perfil de Dívida

  • Dívida total por tipo (tabela)
  • APR (Taxa Anual Percentual) média
  • Cronograma de quitação (método avalanche)
  • Custo de juros na trajetória atual vs. acelerada

Página 6: Perspectiva de Aposentadoria

  • Anos até a aposentadoria
  • Saldo atual vs. benchmark de idade
  • Saldo projetado na aposentadoria (3 cenários: conservador / moderado / agressivo)
  • Saldo necessário para o estilo de vida desejado
  • Análise de lacunas
  • Taxa de contribuição recomendada

Página 7: Carteira de Investimentos

  • Gráfico de pizza da alocação atual
  • Gráfico de pizza da alocação recomendada
  • Deriva / necessidades de rebalanceamento
  • Análise de taxa de despesa
  • Pontuação de diversificação

Página 8: Proteção Financeira

  • Status do fundo de emergência
  • Matriz de cobertura de seguros (saúde, vida, invalidez, auto, casa)
  • Checklist de planejamento sucessório (testamento, beneficiários, procuração, diretiva de cuidados de saúde)
  • Lacunas e preenchimentos prioritários

Páginas 9-10: Plano de Ação

  • Prioridades de 30 dias
  • Prioridades de 90 dias
  • Prioridades de 1 ano
  • Prioridades de 5 anos
  • Cada ação inclui: valor monetário específico, conta/veículo específico, data de vencimento

Página Final: Divulgações e Glossário

  • Aviso legal completo
  • Notas de metodologia
  • Glossário de termos (DTI, SWR, ER, etc.)
  • "Próximos passos" — quando consultar profissionais

Padrões de Design Visual

  • Paleta de cores: Azul (#1f4e79) primário, verde para métricas positivas, âmbar para avisos, vermelho para críticos
  • Tipografia: Sans-serif para títulos, serifada para corpo
  • Gráficos: Limpos, linhas de grade mínimas, rótulos em linguagem simples
  • Medidores: Escala 0-100 com zonas codificadas por cor (vermelho <40, âmbar 40-69, verde 70+)
  • Tabelas: Sombreamento alternado de linhas, números alinhados à direita, formatação de moeda com separadores de milhar

Tom e Linguagem

  • Inglês simples, sem jargão excessivo
  • Números específicos, nunca faixas vagas
  • Empático em relação a deficiências, concreto em relação a ações
  • Confiante em relação a pontos fortes

Tratamento de Erros

ErroResposta
Nenhum arquivo FINANCE-*.md encontrado"Execute /finance analyze ou /finance quick primeiro para gerar os dados de entrada."
Script Python ausenteGere FINANCE-PLAN.md consolidado em vez disso; informe ao usuário como instalar o ReportLab
ReportLab não instaladoInstrua: pip3 install reportlab
Markdown vazio/malformadoPule essa seção, gere o PDF sem ela, anote no resumo
Geração de PDF bem-sucedida, mas arquivo < 50KBProvavelmente sem dados; avise o usuário

Opções de Personalização

Se o usuário quiser personalizar:

  • Nome na capa — Pergunte pelo nome do agregado familiar para exibir
  • Seções seletivas — Permita /finance report-pdf --sections=debt,retirement para limitar o escopo
  • Marca — Se for uso de consultor, permita injeção de caminho do logotipo
  • Moeda — Padrão USD; permita substituição

Lista de Verificação de Validação

Antes de declarar sucesso, verifique:

  • [ ] O arquivo PDF existe no caminho esperado
  • [ ] Tamanho do arquivo > 50KB (verificação de sanidade aproximada)
  • [ ] O aviso legal aparece na capa e na página final
  • [ ] Todas as pontuações de categoria estão presentes (não "N/D" para tudo)
  • [ ] Pelo menos 3 itens de ação no plano
