💰 /finance quick — Vista Rápida Financiera en 60 Segundos

**AVISO: Solo para fines educativos/informativos. No constituye asesoramiento financiero.**

11
Temas

Lectura
orquestador
Comando
Finanzas
Equipo

AVISO: Solo con fines educativos e informativos. No constituye asesoramiento financiero.

Objetivo

Entrega un panel de salud financiera de alto impacto en menos de 60 segundos, sin iniciar el análisis completo de 5 agentes. Usa este recurso cuando el usuario quiera una lectura rápida de su situación antes de comprometerse con una auditoría más profunda.

Cuándo activar

  • El usuario escribe /finance quick
  • El usuario pregunta «¿cómo estoy financieramente?», «¿cuál es mi salud financiera?», «revisión rápida de mis finanzas»
  • El usuario desea una línea de base antes de decidir ejecutar /finance analyze

NO inicies subagentes

Esta skill debe completarse en una sola respuesta después de recopilar los datos. Sin agentes paralelos. Sin llamadas a API externas. Todos los cálculos los realiza el modelo base directamente.

Entradas obligatorias

Pídele al usuario estos seis números en un solo prompt. Acepta estimaciones aproximadas; no se necesita precisión para obtener una visión rápida.

  1. Ingresos netos mensuales (dólares después de impuestos que llegan a la cuenta)
  2. Gastos mensuales (alquiler/hipoteca + servicios públicos + alimentación + transporte + todo lo demás)
  3. Total de ahorros netos (cuenta corriente + ahorros + efectivo en cuentas de corretaje, NO cuentas de jubilación)
  4. Total de deudas (tarjetas de crédito + préstamos estudiantiles + financiamiento de vehículo + saldo del financiamiento inmobiliario)
  5. Edad actual
  6. Edad objetivo para la jubilación

Si el usuario proporciona solo datos parciales, calcula lo que sea posible y señala los campos que faltan en el resultado.

Cálculos

1. Tasa de ahorro

savings_rate = (monthly_income - monthly_expenses) / monthly_income * 100

Métricas de referencia:

  • 20%+ → Excelente
  • 15-19% → Bueno
  • 10-14% → Razonable
  • 5-9% → Débil
  • <5% → Crítico

2. Relación deuda-ingresos (DTI)

monthly_debt_payments = estimate as ~2% of total_debt (rough proxy)
DTI = monthly_debt_payments / monthly_income * 100

Métricas de referencia:

  • <15% → Excelente
  • 15-28% → Saludable
  • 28-36% → Manejable
  • 36-43% → Bajo tensión
  • >43% → Crítico

3. Cobertura del fondo de emergencia

months_covered = total_savings / monthly_expenses

Métricas de referencia:

  • 6+ meses → Excelente
  • 3-5.9 meses → Bueno
  • 1-2.9 meses → Débil
  • <1 mes → Crítico

4. Estado del plan de jubilación

Usa el multiplicador de referencia de los ingresos anuales actuales según la edad:

  • Edad 30 → 1x ingresos ahorrados
  • Edad 35 → 2x ingresos
  • Edad 40 → 3x ingresos
  • Edad 45 → 4x ingresos
  • Edad 50 → 6x ingresos
  • Edad 55 → 7x ingresos
  • Edad 60 → 8x ingresos
  • Edad 67 → 10x ingresos

Compara los ahorros reales para la jubilación del usuario (si se proporcionan; de lo contrario, asume que los ahorros netos son el mínimo) con la métrica de referencia para su edad. Calcula los años hasta la jubilación = target_retirement_age - current_age.

5. Puntuación rápida compuesta (0-100)

quick_score = (savings_rate_score + dti_score + emergency_score + retirement_score) / 4

Cada subpuntuación es de 0-100 según las métricas de referencia anteriores.

Nota:

  • 85-100 → A
  • 70-84 → B
  • 55-69 → C
  • 40-54 → D
  • <40 → F

Formato de salida

Mantén la salida en menos de 40 líneas en total. Usa ASCII simple (sin tablas Markdown para la versión de terminal, pero incluye un formato de tabla compacto).

================================================
  VISÃO RÁPIDA FINANCEIRA EM 60 SEGUNDOS

Lógica de acciones prioritarias

Clasifica las acciones según la métrica más débil:

  • Si el fondo de emergencia < 1 mes → Acción principal: "Construye un fondo de emergencia de $X (mínimo de 1 mes) antes de cualquier otra medida"
  • Si el DTI > 43% → Pago agresivo de deudas: lista primero la deuda con el APR más alto y apunta a pagar $X extra/mes
  • Si la tasa de ahorro < 5% → Acción principal: "Audita las 3 principales categorías de gastos: encuentra $X que puedas recortar este mes"
  • Si la jubilación está críticamente atrasada → Acción principal: "Abre o aumenta tu aporte para la jubilación en $X/mes (meta del 15% de los ingresos brutos)"
  • Si hay deudas con intereses altos (asume que son tarjetas de crédito si total_debt > 0 y el usuario ha reportado alguna) → "Paga primero la deuda con el APR más alto antes de hacer inversiones adicionales"

Si las cuatro métricas son saludables, presenta acciones de optimización:

  • "Aumenta tu contribución para la jubilación para aprovechar al máximo el aporte equivalente del empleador"
  • "Transfiere el fondo de emergencia a una cuenta de ahorros de alto rendimiento (4-5% APY frente a 0.01%)"
  • "Diversifica más allá del efectivo: empieza a invertir periódicamente en fondos indexados"

Ejemplo paso a paso

Entradas del usuario:

  • Ingresos: $7.500/mes
  • Gastos: $6.200/mes
  • Ahorros: $8.000
  • Deudas: $32.000 (principalmente préstamos estudiantiles)
  • Edad: 31
  • Edad objetivo de jubilación: 65

Calculado:

  • Tasa de ahorro: 17,3% → Bueno
  • DTI: ~8,5% → Excelente
  • Fondo de emergencia: 1,29 meses → Débil
  • Jubilación: faltan 34 años para jubilarte, $8K ahorrados, referencia a los 31 años: ~$90K → Muy atrasado

Puntuación: (75 + 95 + 35 + 25) / 4 = 57,5 → C

Top 3 acciones:

  1. Construir el fondo de emergencia de $8K a $18.600 (3 meses): redirigir $1.000/mes durante 11 meses
  2. Abre una Roth IRA y aporta $583/mes (máximo de $7.000/año) a partir de este mes
  3. Refinanciar/consolidar préstamos estudiantiles si la APR > 6% — puede ahorrar $X/año

Casos extremos

  • El usuario no proporciona deudas → Omitir la puntuación DTI y ponderar las demás por igual
  • El usuario está jubilado → Sustituir el plan de jubilación por la sostenibilidad de los retiros (verificación de la regla del 4%)
  • El usuario tiene menos de 25 años → Usar métricas de jubilación más bajas (0,5x a los 25); enfatizar empezar ahora
  • El usuario tiene ingresos muy altos (>$300K/año) → Agregar nota: las cuentas con ventajas fiscales pueden tener límites; mencionar backdoor Roth, mega-backdoor, HSA
  • El usuario se niega a compartir cifras → Ofrecer 3 escenarios hipotéticos (difícil / promedio / sólido) y dejar que se identifique con uno

Transición

Termina cada resumen rápido con la línea:

Ejecuta /finance analyze para el análisis exhaustivo de 5 agentes, o /finance debt / /finance retirement para trabajar con concentración.

Tono

Directo. Cuantitativo. Sin lenguaje dubitativo como "puedes considerar". Di "haz X esta semana" con montos específicos en dólares. Reconoce los logros ("una tasa de ahorro del 17% está por encima de la mediana de EE. UU.") antes de señalar las brechas.

AVISO: Solo con fines educativos e informativos. No constituye asesoramiento financiero. Consulta con un asesor financiero autorizado, un CPA o un profesional de impuestos antes de tomar decisiones financieras importantes.
