🚀 Cómo usar este equipo

Resumen de los comandos del orquestador — cada módulo detalla el componente correspondiente.

Cómo usar

  1. Abre el asistente y escribe /finance <comando>.
  2. Comandos principales:
  • /finance analyze — análisis completo de salud financiera
  • /finance quick — vista rápida (60 segundos)
  • /finance budget — análisis de gastos y presupuesto
  • /finance emergency — fondo de emergencia
  • /finance debt — estrategia de pago de deudas
  • /finance retirement — análisis de jubilación
  • /finance goals — plan de objetivos financieros
  • /finance portfolio — asignación de cartera
  • /finance taxes — optimización fiscal
  • /finance networth — patrimonio neto e hitos
  • /finance screen <critérios> — filtro de inversiones
  • /finance report-pdf — generar plan financiero en PDF

Recomendación de modelo: un modelo con una ventana de contexto grande (64k+) para admitir análisis completos.

Aviso: contenido educativo — no constituye asesoramiento financiero profesional. Consulta a un planificador financiero o contador habilitado para tomar decisiones concretas.
