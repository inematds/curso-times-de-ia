Propósito de la Skill

Genera un informe de estrategia publicitaria en PDF, listo para el cliente, con la biblioteca Python ReportLab. Esta skill revisa el directorio de trabajo actual en busca de todos los archivos de resultados publicitarios, extrae puntuaciones, perfiles de audiencia, estructura de campañas, asignación de presupuesto e información competitiva, los compila en un JSON estructurado y produce un PDF profesional con una portada que incluye un indicador de Puntuación de Preparación para Anuncios, tarjetas de perfiles de audiencia, diagrama del embudo de campañas, gráfico de asignación de presupuesto, mapa de posicionamiento competitivo, resumen de la dirección creativa y un plan de acción priorizado de 90 días.

Cuándo usar

  • El usuario desea una versión en PDF del informe de estrategia publicitaria (no solo Markdown)
  • El usuario está preparando un entregable para una presentación a un cliente o a partes interesadas
  • El usuario solicita un «informe pulido», «informe listo para el cliente» o «informe en PDF»
  • El usuario desea un informe visual con gráficos, puntuaciones y formato profesional
  • Activado por /ads report-pdf o /ads report-pdf <nome do negócio>

Cuándo usar PDF vs. Markdown

FormatoMejor paraVentajasDesventajas
PDFPresentaciones para clientes, archivos adjuntos de correo electrónico, propuestas, material de ventasApariencia profesional, gráficos y medidores, imprimible, formato coherenteRequiere un script de Python, más difícil de editar
MarkdownUso interno, referencia rápida, edición iterativa, control de versionesFácil de editar, generación rápida, compatible con gitMenos acabado visual, sin gráficos

Regla general: Si el informe se enviará a un cliente, prospecto o ejecutivo, usa PDF. Si es para uso interno o edición posterior, usa Markdown.

Cómo ejecutar

Etapa 1: Verificar el script de generación de PDF

Primero, verifica si existe el script dedicado para generar PDF:

ls ~/.claude/skills/ads/scripts/generate_ads_pdf.py 2>/dev/null

Si el script existe: Úsalo directamente (salta a la Etapa 4). Si el script no existe: Genera el PDF en línea con ReportLab (sigue todos los pasos).

Etapa 2: Recopilar todos los datos disponibles

Busca en el directorio de trabajo actual todas las salidas de la skill de anuncios. Busca estos archivos:

Fuentes de datos primarias (busca todas estas):

  • ADS-STRATEGY-*.md — Informe completo de estrategia (puntuaciones compuestas, todas las secciones)
  • ADS-AUDIENCE*.md — Perfiles de audiencia, parámetros de segmentación
  • ADS-COPY-*.md — Texto publicitario específico para cada plataforma
  • ADS-HOOKS*.md — Ganchos para detener el scroll
  • ADS-CREATIVE-BRIEF*.md — Briefings creativos para todos los formatos
  • ADS-VIDEO-SCRIPTS*.md — Guiones para anuncios en video
  • ADS-FUNNEL*.md — Arquitectura del embudo de campañas
  • ADS-BUDGET*.md — Plan de asignación de presupuesto
  • ADS-COMPETITORS*.md — Inteligencia competitiva
  • ADS-KEYWORDS*.md — Estrategia de palabras clave (Google Ads)
  • ADS-TESTING-PLAN*.md — Plan de pruebas A/B
  • ADS-LANDING*.md — Auditoría de página de destino
  • ADS-AUDIT*.md — Resultados de la auditoría de rendimiento

Comando de búsqueda:

ls ADS-*.md 2>/dev/null

Para cada archivo encontrado, extrae:

  • Puntuaciones y evaluaciones
  • Principales descubrimientos y recomendaciones
  • Personas de audiencia y segmentos
  • Detalles de la estructura de campañas
  • Asignaciones de presupuesto y proyecciones
  • Datos de posicionamiento competitivo
  • Mejores textos y ganchos
  • Elementos de acción y cronogramas

Etapa 4: Generar el PDF

Ejecuta el script de generación de PDF con los datos JSON compilados:

python3 ~/.claude/skills/ads/scripts/generate_ads_pdf.py

Si el script no existe, genéralo en línea. El script debe producir un PDF con estas secciones:

Estructura y páginas del PDF

Página 1: Portada

  • Título del informe: "Informe de estrategia de anuncios"
  • Nombre del negocio y espacio reservado para el logotipo
  • URL del sitio web
  • Fecha del informe
  • "Preparado por un estratega de anuncios con IA"
  • Medidor de puntuación de preparación para anuncios (grande, centrado) — codificado por colores:
  • 80-100: Verde (#059669)
  • 60-79: Azul (#2563EB)
  • 40-59: Amarillo (#D97706)
  • 20-39: Naranja (#EA580C)
  • 0-19: Rojo (#DC2626)

Página 2: Resumen ejecutivo

  • Desglose de la puntuación de preparación para anuncios (5 categorías con puntuaciones individuales)
  • Gráfico de barras horizontales que muestra la puntuación de cada categoría respecto al máximo
  • 3 hallazgos críticos (en viñetas, en negrita)
  • 3 logros rápidos (en viñetas, con impacto estimado)
  • Declaración del veredicto general

Página 3: Análisis del público

  • Puntuación de claridad del público: X/100
  • Tarjetas de personas (2-3 personas), cada una con:
  • Nombre de la persona y resumen demográfico
  • Principales 3 puntos de dolor
  • Principales 3 motivaciones
  • Plataformas preferidas
  • Resumen de los parámetros de segmentación
  • Gráfico de presencia en plataformas (gráfico de barras por plataforma)

Página 4: Dirección creativa

  • Puntuación de calidad creativa: X/100
  • Top 5 ganchos con recomendaciones de plataforma
  • Ejemplos de mejores títulos/textos (3-5)
  • Tabla de recomendaciones de formatos creativos
  • Prioridades de pruebas A/B

Página 5: Arquitectura de campañas

  • Puntuación de la arquitectura del embudo: X/100
  • Diagrama del embudo (flujo visual): `` CONSCIÊNCIA → CONSIDERAÇÃO → CONVERSÃO → RETENÇÃO [Campanha] [Campanha] [Campanha] [Campanha] [% Orçamento] [% Orçamento] [% Orçamento] [% Orçamento] ``
  • Tabla de estructura de campañas (nombre de la campaña, objetivo, público, plataforma)
  • Descripción del flujo de retargeting

Página 6: Posicionamiento competitivo

  • Puntuación de posicionamiento competitivo: X/100
  • Tabla de comparación de competidores (nombre, gasto estimado, mensaje clave, brecha)
  • Oportunidades de posicionamiento (en viñetas)
  • Recomendaciones para diferenciar los mensajes

Página 7: Asignación de presupuesto

  • Puntuación de eficiencia presupuestaria: X/100
  • Gráfico circular: asignación del presupuesto por plataforma
  • Gráfico de barras: asignación del presupuesto por etapa del embudo
  • Tabla de métricas proyectadas: | Métrica | Mes 1 | Mes 2 | Mes 3 | |--------|---------|---------|---------| | Gasto | $X | $X | $X | | Impresiones | X | X | X | | Clics | X | X | X | | Conversiones | X | X | X | | CPA | $X | $X | $X | | ROAS | Xx | Xx | Xx |
  • Mapa de escala (cuándo aumentar el presupuesto y cuánto)

Página 8: Plan de acción de 90 días

  • Tabla de prioridades codificada por colores:
  • Semana 1 (Rojo/Urgente): Acciones de configuración inmediata
  • Semanas 2-4 (Naranja/Importante): Lanzamiento y optimización inicial
  • Mes 2-3 (Azul/Estratégico): Escala y expansión
  • Cada acción incluye: tarea, responsable, plataforma, impacto estimado
  • Hitos clave y puntos de verificación

Página 9: Apéndice (si hay datos disponibles)

  • Lista completa de palabras clave (si /ads keywords se ejecutó)
  • Biblioteca completa de copies de anuncios (si /ads copy se ejecutó)
  • Resumen de la auditoría de la página de destino (si /ads landing se ejecutó)
  • Plan de pruebas A/B (si /ads testing se ejecutó)

Especificaciones de diseño del PDF

Diseño:

  • Tamaño de página: Letter (8.5" x 11")
  • Márgenes: 0.75" en todos los lados
  • Encabezado: Nombre del negocio (izquierda), número de página (derecha)
  • Pie de página: «Generado por Estratega de Anuncios con IA» (centro)

Colores:

  • Primaria: #1E3A5F (azul marino oscuro — encabezados, títulos)
  • Secundaria: #2563EB (azul — acentos, destacados, enlaces)
  • Fondo: #F8FAFC (gris claro — fondos de secciones)
  • Texto: #1F2937 (gris oscuro — texto del cuerpo)
  • Éxito: #059669 (verde — puntuaciones positivas, fortalezas)
  • Aviso: #D97706 (ámbar — puntuaciones medias, cautela)
  • Peligro: #DC2626 (rojo — puntuaciones bajas, problemas críticos)

Tipografía:

  • Títulos: Helvetica-Bold, 16pt (h1), 13pt (h2), 11pt (h3)
  • Cuerpo: Helvetica, 10pt
  • Tablas: Helvetica, 9pt
  • Subtítulos: Helvetica, 8pt, gris

Gráficos (ReportLab Drawing):

  • Medidor de puntuación: gráfico de arco/anillo con el número de puntuación centrado
  • Gráficos de barras: barras horizontales con etiquetas de valor
  • Gráficos circulares: con etiquetas de porcentaje y leyenda
  • Diagrama del embudo: Formas trapezoidales con etiquetas

Etapa 5: Posgeneración

Después de generar el PDF:

  1. Verifica si se creó el archivo:
ls -la ADS-STRATEGY-REPORT.pdf
  1. Informar al usuario el tamaño y la ubicación del archivo
  2. Sugiere los próximos pasos:
  • Revisa el PDF y compártelo con el cliente o el equipo
  • Ejecuta /ads audit después de 7 días de datos de la campaña
  • Usa skills individuales para regenerar secciones específicas

Tratamiento de datos faltantes

Es posible que no se hayan ejecutado todas las skills antes de generar el PDF. Trátalo adecuadamente:

Datos disponiblesComportamiento
Ejecución completa de la estrategia (los 5 agentes)Generar un informe completo con todas las páginas
Datos parciales (algunos agentes)Generar un informe con las secciones disponibles y marcar las secciones faltantes como "Aún no analizado"
Solo foto rápidaGenerar un mininforme (portada + resumen ejecutivo + plan de acción)
No se encontró ningún archivo de datosInformar al usuario que ejecute /ads strategy <url> primero

Datos mínimos necesarios: Al menos un archivo ADS-*.md debe existir. Si no se encuentra ninguno, mostrar:

Nenhum dado de estratégia de anúncios encontrado no diretório atual.
Execute '/ads strategy <url>' primeiro para gerar a análise,
e então use '/ads report-pdf' para criar o relatório em PDF.

Salida

El resultado final es un único archivo PDF: ADS-STRATEGY-REPORT.pdf

Guardado en el directorio de trabajo actual, junto con los archivos fuente en Markdown.

Reglas importantes

  • Siempre verifica los archivos de datos existentes antes de generar: nunca crees un PDF con datos vacíos o marcadores de posición
  • El PDF debe estar listo para presentárselo al cliente sin ninguna edición
  • Los medidores de puntuación deben usar códigos de colores para que el rendimiento se vea al instante
  • Los gráficos deben tener etiquetas claras: ningún eje ni leyenda sin etiquetar
  • Si el script falla, proporciona el mensaje de error exacto y sugiere instalar ReportLab: pip3 install reportlab
  • El indicador de puntuación de la portada es el elemento visual más importante: debe ser destacado y preciso
  • Las proyecciones de presupuesto deben etiquetarse como estimaciones, no como garantías
  • Siempre incluye el plan de acción de 90 días: es la sección más práctica para los clientes
  • Los números de página y los encabezados y pies de página deben ser consistentes en todas las páginas
  • Si los datos son parciales, indica claramente qué secciones tienen datos completos y cuáles contienen estimaciones
  • El nombre del archivo PDF siempre debe ser ADS-STRATEGY-REPORT.pdf para mantener la consistencia
  • El tamaño del archivo debe ser inferior a 5 MB; optimiza la renderización de los gráficos si es necesario
