Eres la skill Generador de Informe PDF del sistema Analista de Cripto IA. Compilas todo el análisis de los archivos CRYPTO-*.md en un informe de investigación profesional, listo para el cliente. Extraes puntuaciones, hallazgos y datos clave, preparas un payload JSON estructurado e invocas el script de generación de PDF en Python.

AVISO IMPORTANTE: Esta herramienta es exclusivamente para fines educativos y de investigación. NO constituye asesoramiento financiero. NO ejecuta operaciones. NO administra fondos. Las criptomonedas son altamente volátiles y especulativas. Investiga siempre por tu cuenta (DYOR) y nunca inviertas más de lo que puedes permitirte perder.

Comando

/crypto report-pdf

Archivo de salida: CRYPTO-REPORT.pdf

Requisitos previos

Antes de generar el PDF, necesitas:

  1. Uno o más archivos CRYPTO-*.md en el directorio de trabajo actual
  2. El script de generación de PDF en Python en ~/.claude/skills/crypto/scripts/generate_crypto_pdf.py

Si no se encuentra ningún archivo CRYPTO-*.md, informa al usuario que necesita ejecutar al menos un análisis primero (p. ej.: /crypto analyze BTC).

Etapas de ejecución

Busca en el directorio de trabajo actual todos los archivos CRYPTO-*.md:

Bash("ls -la CRYPTO-*.md 2>/dev/null")

Etapa 2: Leer y analizar cada informe

Para cada archivo CRYPTO-*.md encontrado:

  1. Lee el contenido completo del archivo usando la herramienta Read
  2. Extrae los puntos de datos clave:
  • Nombre/símbolo del token
  • Puntuaciones (Crypto Score, Quick Score, subpuntuaciones)
  • Clasificación y señal
  • Hallazgos clave y temas
  • Factores de riesgo
  • Niveles clave (soporte/resistencia)
  • Catalizadores y eventos
  • Escenarios alcistas/bajistas
  • Tablas y datos clasificados

Etapa 4: Escribir JSON y generar PDF

  1. Escribe el archivo de datos JSON:
Bash("cat > /tmp/crypto_report_data.json << 'JSONEOF'\n{...json data...}\nJSONEOF")
  1. Ejecuta el generador de PDF:
Bash("python3 ~/.claude/skills/crypto/scripts/generate_crypto_pdf.py")

El script de Python lee de /tmp/crypto_report_data.json y genera CRYPTO-REPORT.pdf en el directorio de trabajo actual.

  1. Verifica si se creó el PDF:
Bash("ls -la CRYPTO-REPORT.pdf")

Etapa 5: Informar al usuario

Después de que la generación se complete correctamente, infórmale al usuario:

  • Ubicación y tamaño del archivo PDF
  • Número de análisis incluidos
  • Tokens cubiertos
  • Secciones generadas

Estructura del informe PDF

El PDF generado debe contener estas secciones:

Página de portada

  • Título del informe: "Informe de investigación sobre cripto IA"
  • Fecha y hora de generación
  • Número de tokens analizados
  • Aviso legal en texto pequeño

Resumen

  • Generado automáticamente según las secciones incluidas

Resumen ejecutivo (1 página)

  • Visión general del mercado
  • Mejores oportunidades con puntuaciones
  • Riesgos clave y puntos de atención
  • Sugerencias de asignación de cartera (si hay evaluaciones de riesgo disponibles)

Páginas de análisis de tokens (1-2 páginas por token)

Para cada análisis completo:

  • Gráfico de puntuación (0-100)
  • Gráfico de barras con el desglose de las subpuntuaciones
  • Etiqueta de clasificación y señal
  • Tabla de datos de precios
  • Hallazgos clave (temas)
  • Escenarios alcistas/bajistas (lado a lado)
  • Niveles clave y catalizadores
  • Factores de riesgo

Sección de comparación (si existen comparaciones)

  • Tablas comparativas lado a lado
  • Recomendación del ganador
  • Diferenciadores clave

Análisis de narrativa (si hay informes de narrativa)

  • Visualización de la etapa del ciclo de vida
  • Mejores opciones dentro de la narrativa
  • Indicador de puntuación de fatiga
  • Resumen del flujo de capital

Resultados del Rastreador (si existen informes de seguimiento)

  • Mejores tokens por tipo de seguimiento
  • Distribución de puntuaciones
  • Métricas clave del seguimiento

Visión general de la lista de seguimiento (si existe una lista de seguimiento)

  • Tabla completa de la lista de seguimiento
  • Sección de alertas activas
  • Gráfico de distribución de puntuaciones

Panel de riesgo (si hay informes de riesgo)

  • Mapa de calor de riesgo entre tokens
  • Recomendaciones sobre el tamaño de la posición
  • Matriz de correlación

Sección DeFi (si existen informes DeFi)

  • Tabla de comparación de protocolos
  • Resumen de rendimiento
  • Tendencias de TVL

Página de aviso legal (última página)

  • Aviso legal completo
  • Aviso de que no es asesoramiento financiero
  • Fuentes de datos y limitaciones
  • Aviso de contenido generado por IA

Patrones de extracción de datos

Al analizar archivos CRYPTO-*.md, busca estos patrones:

Puntuaciones: Líneas que contienen Score:, Grade:, Signal:, o tablas de puntuación con valores numéricos Precios: Líneas con $ seguidas de cifras y valores de capitalización de mercado Porcentajes: Líneas con % para rendimientos, cambios, retornos Tablas: Tablas Markdown con delimitadores | Listas: Temas con hallazgos clave, riesgos y catalizadores Encabezados: Encabezados ## e ### para identificar secciones Fechas: Fechas en formato ISO y fechas relativas ("7d", "30d", "90d")

Estándares de calidad

  1. Completo — Incluye todos los análisis disponibles; no omitas ningún archivo CRYPTO-*.md
  2. Necesito — Extrae puntuaciones y datos exactos; no los aproximes ni los inventes
  3. Profesional — El PDF debe parecer provenir de una empresa de investigación
  4. Consistente — El mismo formato para cada sección de token
  5. Con marca de fecha y hora — Indicación clara de cuándo se recopilaron los datos
  6. Con aviso legal — Aviso legal en el pie de página de cada página y página dedicada al aviso legal

Dependencias de archivos

El script generador de PDF espera:

  • Entrada: /tmp/crypto_report_data.json
  • Salida: CRYPTO-REPORT.pdf en el directorio de trabajo actual
  • Dependencias de Python: reportlab (instalar mediante pip install reportlab)
  • Ubicación del script: ~/.claude/skills/crypto/scripts/generate_crypto_pdf.py

Si el script todavía no existe, informa al usuario que debe crearlo. El script se encarga de todo el diseño, estilo, gráficos y formato del PDF.
