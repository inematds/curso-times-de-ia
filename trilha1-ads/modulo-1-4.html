Propósito da Skill

Gerar um relatório de estratégia de anúncios em PDF, pronto para o cliente, utilizando a biblioteca Python ReportLab. Esta skill varre o diretório de trabalho atual em busca de todos os arquivos de saída de anúncios, extrai pontuações, personas de público, estrutura de campanhas, alocação de orçamento e inteligência competitiva, compila-os em JSON estruturado e produz um PDF profissional com uma página de capa contendo um medidor de Pontuação de Prontidão para Anúncios, cartões de personas de público, diagrama de funil de campanhas, gráfico de alocação de orçamento, mapa de posicionamento competitivo, resumo da direção criativa e um plano de ação priorizado de 90 dias.

Quando Usar

  • O usuário deseja uma versão em PDF do relatório de estratégia de anúncios (não apenas Markdown)
  • O usuário está preparando um entregável para uma apresentação ao cliente ou a partes interessadas
  • O usuário solicita um "relatório polido", "relatório pronto para o cliente" ou "relatório em PDF"
  • O usuário deseja um relatório visual com gráficos, pontuações e formatação profissional
  • Disparado por /ads report-pdf ou /ads report-pdf <nome do negócio>

Quando Usar PDF vs Markdown

FormatoMelhor ParaVantagensDesvantagens
PDFApresentações para clientes, anexos de e-mail, propostas, material de vendasAparência profissional, gráficos e medidores, imprimível, formatação consistenteRequer script Python, mais difícil de editar
MarkdownUso interno, referência rápida, edição iterativa, controle de versãoFácil de editar, geração rápida, compatível com gitMenos polimento visual, sem gráficos

Regra geral: Se o relatório for enviado a um cliente, prospect ou executivo, use PDF. Se for para uso interno ou edição posterior, use Markdown.

Como Executar

Etapa 1: Verificar o Script de Geração de PDF

Primeiro, verifique se o script dedicado de geração de PDF existe:

ls ~/.claude/skills/ads/scripts/generate_ads_pdf.py 2>/dev/null

Se o script existir: Use-o diretamente (pule para a Etapa 4). Se o script não existir: Gere o PDF inline usando ReportLab (siga todas as etapas).

Etapa 2: Coletar Todos os Dados Disponíveis

Varra o diretório de trabalho atual em busca de todas as saídas da skill de anúncios. Busque por estes arquivos:

Fontes de dados primárias (busque por todas estas):

  • ADS-STRATEGY-*.md — Relatório de estratégia completo (pontuações compostas, todas as seções)
  • ADS-AUDIENCE*.md — Personas de público, parâmetros de segmentação
  • ADS-COPY-*.md — Copy de anúncios específica por plataforma
  • ADS-HOOKS*.md — Ganchos para parar o scroll
  • ADS-CREATIVE-BRIEF*.md — Briefings criativos para todos os formatos
  • ADS-VIDEO-SCRIPTS*.md — Roteiros de anúncios em vídeo
  • ADS-FUNNEL*.md — Arquitetura do funil de campanhas
  • ADS-BUDGET*.md — Plano de alocação de orçamento
  • ADS-COMPETITORS*.md — Inteligência competitiva
  • ADS-KEYWORDS*.md — Estratégia de palavras-chave (Google Ads)
  • ADS-TESTING-PLAN*.md — Plano de testes A/B
  • ADS-LANDING*.md — Auditoria de página de destino
  • ADS-AUDIT*.md — Resultados de auditoria de desempenho

Comando de busca:

ls ADS-*.md 2>/dev/null

Para cada arquivo encontrado, extraia:

  • Pontuações e avaliações
  • Principais descobertas e recomendações
  • Personas de público e segmentos
  • Detalhes da estrutura de campanhas
  • Alocações de orçamento e projeções
  • Dados de posicionamento competitivo
  • Melhores copies e ganchos
  • Itens de ação e cronogramas

Etapa 4: Gerar o PDF

Execute o script de geração de PDF com os dados JSON compilados:

python3 ~/.claude/skills/ads/scripts/generate_ads_pdf.py

Se o script não existir, gere-o inline. O script deve produzir um PDF com estas seções:

Estrutura e Páginas do PDF

Página 1: Capa

  • Título do relatório: "Relatório de Estratégia de Anúncios"
  • Nome do negócio e espaço reservado para logotipo
  • URL do site
  • Data do relatório
  • "Preparado por Estrategista de Anúncios IA"
  • Medidor de Pontuação de Prontidão para Anúncios (grande, centralizado) — codificado por cores:
  • 80-100: Verde (#059669)
  • 60-79: Azul (#2563EB)
  • 40-59: Amarelo (#D97706)
  • 20-39: Laranja (#EA580C)
  • 0-19: Vermelho (#DC2626)

Página 2: Resumo Executivo

  • Detalhamento da Pontuação de Prontidão para Anúncios (5 categorias com pontuações individuais)
  • Gráfico de barras horizontais mostrando a pontuação de cada categoria em relação ao máximo
  • 3 descobertas críticas (em tópicos, em negrito)
  • 3 vitórias rápidas (em tópicos, com impacto estimado)
  • Declaração de veredito geral

Página 3: Análise de Público

  • Pontuação de Clareza do Público: X/100
  • Cartões de personas (2-3 personas), cada um contendo:
  • Nome da persona e resumo demográfico
  • Principais 3 pontos de dor
  • Principais 3 motivações
  • Plataformas preferidas
  • Resumo dos parâmetros de segmentação
  • Gráfico de presença em plataformas (gráfico de barras por plataforma)

Página 4: Direção Criativa

  • Pontuação de Qualidade Criativa: X/100
  • Top 5 ganchos com recomendações de plataforma
  • Exemplos de melhores títulos/copys (3-5)
  • Tabela de recomendações de formatos criativos
  • Prioridades de testes A/B

Página 5: Arquitetura de Campanhas

  • Pontuação de Arquitetura do Funil: X/100
  • Diagrama do funil (fluxo visual): `` CONSCIÊNCIA → CONSIDERAÇÃO → CONVERSÃO → RETENÇÃO [Campanha] [Campanha] [Campanha] [Campanha] [% Orçamento] [% Orçamento] [% Orçamento] [% Orçamento] ``
  • Tabela de estrutura de campanhas (nome da campanha, objetivo, público, plataforma)
  • Descrição do fluxo de retargeting

Página 6: Posicionamento Competitivo

  • Pontuação de Posicionamento Competitivo: X/100
  • Tabela de comparação de concorrentes (nome, gasto estimado, mensagem-chave, lacuna)
  • Oportunidades de posicionamento (em tópicos)
  • Recomendações de diferenciação de mensagens

Página 7: Alocação de Orçamento

  • Pontuação de Eficiência de Orçamento: X/100
  • Gráfico de pizza: Alocação de orçamento por plataforma
  • Gráfico de barras: Alocação de orçamento por etapa do funil
  • Tabela de métricas projetadas: | Métrica | Mês 1 | Mês 2 | Mês 3 | |--------|---------|---------|---------| | Gasto | $X | $X | $X | | Impressões | X | X | X | | Cliques | X | X | X | | Conversões | X | X | X | | CPA | $X | $X | $X | | ROAS | Xx | Xx | Xx |
  • Mapa de escala (quando aumentar o orçamento e em quanto)

Página 8: Plano de Ação de 90 Dias

  • Tabela de prioridade codificada por cores:
  • Semana 1 (Vermelho/Urgente): Ações de configuração imediata
  • Semanas 2-4 (Laranja/Importante): Lançamento e otimização inicial
  • Mês 2-3 (Azul/Estratégico): Escala e expansão
  • Cada item de ação inclui: tarefa, responsável, plataforma, impacto estimado
  • Marcos-chave e pontos de verificação

Página 9: Apêndice (se houver dados disponíveis)

  • Lista completa de palavras-chave (se /ads keywords foi executado)
  • Biblioteca completa de copies de anúncios (se /ads copy foi executado)
  • Resumo da auditoria da página de destino (se /ads landing foi executado)
  • Plano de testes A/B (se /ads testing foi executado)

Especificações de Design do PDF

Layout:

  • Tamanho da página: Letter (8.5" x 11")
  • Margens: 0.75" em todos os lados
  • Cabeçalho: Nome do negócio (esquerda), número da página (direita)
  • Rodapé: "Gerado por Estrategista de Anúncios IA" (centro)

Cores:

  • Primária: #1E3A5F (azul-marinho escuro — cabeçalhos, títulos)
  • Secundária: #2563EB (azul — acentos, destaques, links)
  • Fundo: #F8FAFC (cinza claro — fundos de seções)
  • Texto: #1F2937 (cinza escuro — texto do corpo)
  • Sucesso: #059669 (verde — pontuações positivas, pontos fortes)
  • Aviso: #D97706 (âmbar — pontuações médias, cautela)
  • Perigo: #DC2626 (vermelho — pontuações baixas, problemas críticos)

Tipografia:

  • Títulos: Helvetica-Bold, 16pt (h1), 13pt (h2), 11pt (h3)
  • Corpo: Helvetica, 10pt
  • Tabelas: Helvetica, 9pt
  • Legendas: Helvetica, 8pt, cinza

Gráficos (ReportLab Drawing):

  • Medidor de pontuação: Gráfico de arco/rosca com o número da pontuação centralizado
  • Gráficos de barras: Barras horizontais com rótulos de valor
  • Gráficos de pizza: Com rótulos de porcentagem e legenda
  • Diagrama de funil: Formas trapezoidais com rótulos

Etapa 5: Pós-Geração

Após gerar o PDF:

  1. Verifique se o arquivo foi criado:
ls -la ADS-STRATEGY-REPORT.pdf
  1. Informe o tamanho e a localização do arquivo ao usuário
  2. Sugira próximos passos:
  • Revise o PDF e compartilhe com o cliente ou equipe
  • Execute /ads audit após 7 dias de dados da campanha
  • Use skills individuais para regenerar seções específicas

Tratamento de Dados Ausentes

Nem todas as skills podem ter sido executadas antes de gerar o PDF. Trate isso adequadamente:

Dados DisponíveisComportamento
Execução completa da estratégia (todos os 5 agentes)Gerar relatório completo com todas as páginas
Dados parciais (alguns agentes)Gerar relatório com as seções disponíveis, marcar seções ausentes como "Ainda Não Analisado"
Apenas instantâneo rápidoGerar um mini-relatório (capa + resumo executivo + plano de ação)
Nenhum arquivo de dados encontradoInformar o usuário para executar /ads strategy <url> primeiro

Dados mínimos necessários: Pelo menos um arquivo ADS-*.md deve existir. Se nenhum for encontrado, exibir:

Nenhum dado de estratégia de anúncios encontrado no diretório atual.
Execute '/ads strategy <url>' primeiro para gerar a análise,
e então use '/ads report-pdf' para criar o relatório em PDF.

Saída

A saída final é um único arquivo PDF: ADS-STRATEGY-REPORT.pdf

Salvo no diretório de trabalho atual, junto com os arquivos fonte em Markdown.

Regras Importantes

  • Sempre verifique os arquivos de dados existentes antes de gerar — nunca crie um PDF com dados vazios/placeholders
  • O PDF deve ser apresentável ao cliente sem qualquer edição
  • Os medidores de pontuação devem usar codificação por cores para tornar o desempenho visível instantaneamente
  • Os gráficos devem ter rótulos claros — sem eixos ou legendas sem rótulos
  • Se o script falhar, forneça a mensagem de erro exata e sugira instalar o ReportLab: pip3 install reportlab
  • O medidor de pontuação na página de capa é o visual mais importante — ele deve ser proeminente e preciso
  • As projeções de orçamento devem ser rotuladas como estimativas, não garantias
  • Sempre inclua o plano de ação de 90 dias — é a seção mais acionável para clientes
  • Os números de página e cabeçalhos/rodapés devem ser consistentes em todas as páginas
  • Se os dados forem parciais, marque claramente quais seções têm dados completos vs estimativas
  • O nome do arquivo PDF deve ser sempre ADS-STRATEGY-REPORT.pdf para consistência
  • O tamanho do arquivo deve ser inferior a 5 MB — otimize a renderização dos gráficos se necessário
