Routing Logic

When the user invokes /ads <comando>, route to the appropriate sub-skill.

Complete Advertising Strategy (/ads strategy <url>)

This is the main command. It starts 5 parallel subagents to build a complete advertising strategy:

  1. Agent ads-audience → Audience research, personas, targeting parameters
  2. Agent ads-creative → Ad copy, hooks, creative concepts, video scripts
  3. Agent ads-funnel → Campaign structure, funnel stages, retargeting flows
  4. Agent ads-competitive → Competitor ad analysis, gaps, positioning opportunities
  5. Agent ads-budget → Budget allocation, platform mix, projected ROI

Scoring Methodology (Ad Readiness Score 0-100):

CategoryWeightWhat It Measures
Audience Clarity25%ICP definition, persona depth, targeting accuracy
Creative Quality20%Strength of hooks, copy quality, visual concepts, video scripts
Funnel Architecture20%Campaign structure, stages, retargeting, conversion path
Competitive Position15%Differentiation, competitor gaps, market opportunity
Budget Efficiency20%Allocation strategy, platform mix, projected CPM/CPC/CPA

Ad Readiness Composite Score = Weighted average of all 5 categories

Quick View (/ads quick <url>)

60-second quick listing readiness assessment. Do NOT start subagents. Instead:

  1. Find the homepage using WebFetch
  2. Assess: value proposition clarity, offer strength, trust signals, CTA quality, landing page readiness
  3. Output a quick scorecard containing the top 3 strengths and the top 3 gaps
  4. Recommend which platform to start on and the estimated budget
  5. Keep the output under 40 lines

Individual Commands

For all other commands (/ads audience, /ads copy, route to the corresponding sub-skill.

Platform Detection

Before generating any advertising content, identify the best platforms for this business:

  • Local Service Business (plumber, dentist, HVAC) → Google Ads (search intent), Facebook/Instagram (local targeting), Nextdoor
  • SaaS/Software → Google Ads (search), LinkedIn (B2B), Facebook/Instagram (retargeting), YouTube (demos)
  • E-commerce → Meta (Facebook/Instagram), Google Shopping, TikTok, Pinterest, YouTube
  • Content Creator/Course → YouTube Ads, Instagram, TikTok, retargeting in Facebook Groups
  • Agency/Services → LinkedIn, Google Ads, Facebook, YouTube
  • Restaurant/Hospitality → Instagram, Facebook, Google Ads (local), TikTok

Business Context Detection

Before running any analysis, detect the type of business:

  • SaaS/Software → Focus on: free trial CTAs, demo requests, feature comparisons, ROI messaging
  • E-commerce → Focus on: product showcases, urgency/scarcity, social proof, UGC-style creative
  • Local Business → Focus on: service area targeting, ad ratings/reviews, call extensions, maps
  • Agency/Services → Focus on: case studies, results-driven copy, consultation CTAs, building authority
  • Content Creator/Course → Focus on: transformation promises, testimonials, limited-time pricing, community

Output Standards

All outputs must follow these rules:

  1. Platform-specific — Each ad must meet your platform’s exact specifications and best practices
  2. Ready to copy and paste — Ad copy should be ready to paste into the ad platform without editing
  3. Public first — Start with who you're targeting, then write the ad for them
  4. Data-driven — Include estimated CPM, CPC, and CPA ranges whenever possible
  5. Test-oriented — Always provide A/B variations, never just one version
  6. Customer-ready — Reports should be ready to present to clients without editing

File Outputs

All markdown outputs are saved in the current working directory with descriptive file names. PDF reports generated via Bash(python3 ~/.claude/skills/ads/scripts/generate_ads_pdf.py).
