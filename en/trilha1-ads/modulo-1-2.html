Skill Purpose

Generate 10+ production-ready ad copy variations for a specified ad platform. Each ad is written to the platform’s exact specifications (character limits, format requirements, best practices), includes A/B variations, and uses proven direct-response copywriting frameworks. The output is ready to copy and paste—a media buyer can enter the text directly into the ad platform without editing.

When to Use

  • The user runs /ads copy <plataforma>
  • The user requests ad copy generation for a specific platform
  • Called as a subagent from /ads strategy (the main orchestrator)
  • The user needs ready-to-use ad copy for any major ad platform
  • The user wants multiple copy variations for A/B testing

Entry Requirements

  • Required: Destination platform (google, meta, linkedin, tiktok, youtube, pinterest)
  • Required: Business context — a URL for analysis or previous audience/strategy data
  • Optional: Specific product/service to advertise, target audience persona, offer/promotion details, tone preferences

How to Run

Step 1: Gather Business Context

If a URL is provided, retrieve it using WebFetch and extract:

  • Business name and industry
  • Core value proposition
  • Main products/services and pricing
  • Target Audience Indicators
  • Brand voice and personality
  • Unique selling points (USPs)
  • Social proof elements (reviews, number of customers, years in business)
  • Current Offers or Promotions

If audience data from a previous run of /ads audience, refer to the primary personas.

Run supplementary research:

WebSearch: "[Nome da Empresa]" ads OR advertising
WebSearch: "[Setor]" best performing ad copy examples
WebSearch: "[Setor]" [plataforma] ad examples

Stage 3: Generate Ad Variations Using 4 Copywriting Frameworks

For each ad, apply one of the four frameworks:

Framework 1: PAS (Problem-Agitate-Solve)

  • Problem: State the pain the audience feels
  • Agitate: Twist the knife — make them feel the cost of inaction
  • Resolve: Present the product/service as the relief

Framework 2: AIDA (Attention-Interest-Desire-Action)

  • Attention: Bold opening that stops the scroll
  • Interest: Interesting fact, story, or angle that draws them in
  • Desire: Paint the outcome — what life is like after the purchase
  • Action: Clear and compelling CTA

Framework 3: BAB (Before-After-Bridge)

  • Before: Your current painful situation
  • Then: The transformed state they want
  • Bridge: The product/service that gets them there

Framework 4: 4Ps (Promise-Picture-Proof-Push)

  • Promise: Bold claim or guarantee
  • Image: Vivid Image of the Result
  • Proof: Evidence (testimonial, statistic, case study)
  • Boost: Urgency or scarcity to act now

Step 6: Platform-Specific Best Practices

Include a best practices section at the end of the output:

Google Ads:

  • Pin Headline 1 with the brand name or main keyword for RSAs
  • Use keyword insertion syntax: {KeyWord:Default Text}
  • Include numbers and percentages (they increase CTR)
  • Each title should make sense on its own and in combination
  • Use at least 1 headline with a CTA, 1 with a benefit, and 1 with a keyword

Meta (Facebook/Instagram):

  • The first line must grab attention — only 125 characters appear before "See More"
  • Use line breaks and emojis to improve readability
  • Social proof in the main copy outperforms features
  • Questions as headlines generate 30-50% more engagement
  • Stories Ads: keep text to a minimum and let the visuals carry the message

LinkedIn:

  • Professional but not boring tone — conversational authority works best
  • Statistics and data outperform emotional appeals
  • Tag company pages in Sponsored Content for social proof
  • Message Ads: personalize the subject line and keep the body under 500 words
  • Questions in the intro text generate 50% more clicks

TikTok:

  • Write like a creator, not a brand
  • Use trending language and a casual tone
  • Hashtag strategy: 3-5 relevant hashtags, 1 branded hashtag
  • Spark Ads (boosting organic posts) outperform traditional ads 2:1
  • The first 2 seconds determine whether they watch or scroll

YouTube:

  • Bumper (6s): One message, one visual, one CTA—that’s it
  • Pre-roll (15s): Grab attention in the first 5 seconds before the skip button appears
  • Include a clear verbal CTA + on-screen CTA
  • Cards and end screens extend engagement

Pinterest:

  • Use keyword-rich descriptions (Pinterest is a search engine)
  • Descriptions of 500 characters perform best
  • Include prices in Pin titles when relevant
  • Vertical format (2:3 aspect ratio) gets 60% more engagement
  • Call-to-action language increases clicks by 70%

Quality Checklist

Before delivering the output, verify:

  • [ ] At least 10 ad variations generated
  • [ ] Each ad has an A/B variation
  • [ ] All character counts within platform limits
  • [ ] Character counts are displayed next to each text element
  • [ ] All 4 copy frameworks represented
  • [ ] Ads cover the TOFU, MOFU, and BOFU stages of the funnel
  • [ ] Each ad includes an explanation of “why this works”
  • [ ] Platform-specific formatting is correct (emojis for Meta, professional tone for LinkedIn, etc.)
  • [ ] CTA buttons/text match the platform options
  • [ ] The headline bank is included
  • [ ] The best practices section is included
  • [ ] The output file is named correctly: ADS-COPY-[PLATAFORMA].md

Text Quality Standards

Each piece of ad copy must follow these rules:

  1. Specific instead of vague — "Save 3 hours a week" beats "Save time"
  2. Numbers beat words — "4.9-star rating" beats "Highly rated"
  3. You instead of us — "You’ll get..." beats "We offer..."
  4. Active voice only — "Cut your costs by 40%" beats "Costs can be reduced"
  5. One CTA per ad — Never split attention between two actions
  6. Proof over claims — "Trusted by over 10,000 companies" beats "The best solution"
  7. Benefit Instead of Feature — "Sleep better tonight" beats "Memory foam mattress"
  8. Platform-native tone — TikTok sounds like a friend, LinkedIn sounds like a thought leader, Google sounds like an answer
