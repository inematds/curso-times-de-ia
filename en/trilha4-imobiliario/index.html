🚀 How to Use This Team

Orchestrator command summary — each module details the corresponding component.

How to Use

  1. Open the assistant and type /realestate <comando>.
  2. Main commands:
  • /realestate analyze <endereço> — full property analysis
  • /realestate quick <endereço> — quick overview (60 seconds)
  • /realestate market <cidade/cep> — local market analysis
  • /realestate invest <endereço> — investment analysis (buy-hold/BRRRR/flip)
  • /realestate flip <endereço> — fix-and-flip analysis
  • /realestate mortgage <valor> — financing and affordability
  • /realestate compare <imóvel1> <imóvel2> — side-by-side comparison
  • /realestate screen <critérios> — real estate screener
  • /realestate commercial <endereço> — commercial property
  • /realestate neighborhood <endereço> — neighborhood analysis
  • /realestate comps <endereço> — comparable sales
  • /realestate rental <endereço> — rental income and cash flow
  • /realestate listing <endereço> — professional ad description
  • /realestate report-pdf — generate a report in PDF

Model recommendation: a model with a large context window (64k+) to support comprehensive analyses.
