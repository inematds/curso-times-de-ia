💰 /finance quick — 60-Second Financial Snapshot

WARNING: For educational/informational purposes only. This does not constitute financial advice.

Objective

Deliver a high-impact financial health dashboard in under 60 seconds, without starting the full 5-agent analysis. Use this feature when the user wants a quick read on their situation before committing to a deeper audit.

When to Trigger

  • The user types /finance quick
  • The user asks "how am I doing financially?", "what's my financial health?", "quick check of my finances"
  • The user wants a baseline before deciding whether to proceed /finance analyze

DO NOT Start Subagents

This skill must be completed in a single response after collecting the inputs. No parallel agents. No external API calls. All calculations are performed inline by the base model.

Required Inputs

Ask the user for these six numbers in a single prompt. Accept rough estimates — precision isn’t necessary for a quick overview.

  1. Monthly net income (after-tax dollars deposited into the account)
  2. Monthly expenses (rent/mortgage + utilities + food + transportation + everything else)
  3. Total net savings (checking + savings + cash in brokerage accounts, NOT retirement accounts)
  4. Total debts (credit cards + student loans + vehicle financing + mortgage balance)
  5. Current Age
  6. Target retirement age

If the user provides only partial data, calculate what you can and flag the missing fields in the output.

Calculations

1. Savings Rate

savings_rate = (monthly_income - monthly_expenses) / monthly_income * 100

Benchmark Metrics:

  • 20%+ → Excellent
  • 15-19% → Good
  • 10-14% → Fair
  • 5-9% → Weak
  • <5% → Critical

2. Debt-to-Income Ratio (DTI)

monthly_debt_payments = estimate as ~2% of total_debt (rough proxy)
DTI = monthly_debt_payments / monthly_income * 100

Benchmark Metrics:

  • <15% → Excellent
  • 15–28% → Healthy
  • 28-36% → Manageable
  • 36-43% → Under Stress
  • >43% → Critical

3. Emergency Fund Coverage

months_covered = total_savings / monthly_expenses

Benchmark Metrics:

  • 6+ months → Excellent
  • 3-5.9 months → Good
  • 1–2.9 months → Weak
  • <1 month → Critical

4. Retirement Plan Status

Use the current annual income-by-age benchmark multiplier:

  • Age 30 → 1x income saved
  • Age 35 → 2x income
  • Age 40 → 3x income
  • Age 45 → 4x income
  • Age 50 → 6x income
  • Age 55 → 7x income
  • Age 60 → 8x income
  • Age 67 → 10x income

Compare the user's actual retirement savings (if provided; otherwise, assume net savings as the floor) with the age-based benchmark. Calculate years until retirement = target_retirement_age - current_age.

5. Quick Composite Score (0-100)

quick_score = (savings_rate_score + dti_score + emergency_score + retirement_score) / 4

Each subscore is 0-100 based on the reference metrics above.

Grade:

  • 85-100 → A
  • 70-84 → B
  • 55-69 → C
  • 40-54 → D
  • <40 → F

Output Format

Keep the output under 40 lines total. Use simple ASCII (no Markdown tables for the terminal version, but include a compact table format).

Priority Action Logic

Rank the stocks based on the weakest metric:

  • If the emergency fund is < 1 month → Main action: "Build a $X emergency fund (at least 1 month) before taking any other steps"
  • If DTI > 43% → Main action: "Pay down debt aggressively — list the debt with the highest APR first and aim to pay an extra $X/month"
  • If savings rate < 5% → Main action: "Audit your top 3 spending categories — find $X you can cut this month"
  • If retirement is critically behind → Main action: "Open or increase your retirement contribution by $X/month (target: 15% of gross income)"
  • If there is high-interest debt (assume credit cards if total_debt > 0 and the user has reported any) → "Pay off the debt with the highest APR before making additional investments"

If all four metrics are healthy, present optimization actions:

  • "Increase retirement contributions to capture the full employer match"
  • "Move your emergency fund to a high-yield savings account (4-5% APY vs 0.01%)"
  • "Diversify beyond cash — start dollar-cost averaging into index funds"

Step-by-Step Example

User inputs:

  • Income: $7.500/month
  • Expenses: $6,200/month
  • Savings: $8.000
  • Debts: $32,000 (mostly student loans)
  • Age: 31
  • Target retirement: 65

Calculated:

  • Savings rate: 17.3% → Good
  • DTI: ~8,5% → Excellent
  • Emergency fund: 1.29 months → Weak
  • Retirement: 34 years until retirement, $8K saved, benchmark at age 31 is ~$90K → Critically Behind

Score: (75 + 95 + 35 + 25) / 4 = 57,5 → C

Top 3 actions:

  1. Build an emergency fund from $8K to $18.600 (3 months) — redirect $1.000/month for 11 months
  2. Open a Roth IRA, contribute $583/month ($7.000/year maximum) starting this month
  3. Refinance/consolidate student loans if APR > 6% — could save $X/year

Extreme Cases

  • User provides no debts → Skip the DTI score and weigh the others equally
  • User is retired → Replace the retirement plan with withdrawal sustainability (4% rule check)
  • User is under 25 years old → Use lower retirement benchmarks (0.5x at 25); emphasize starting now
  • User has very high income (>$300K/year) → Add note: tax-advantaged accounts may have limits; mention backdoor Roth, mega-backdoor, HSA
  • User refuses to share numbers → Offer 3 hypothetical scenarios (difficult / average / strong) and let them identify with one

Transition

End each quick take with the line:

Run /finance analyze for the 5-agent deep dive, or /finance debt / /finance retirement for focused work.

Tone

Direct. Quantitative. No hesitant language like "you may want to consider." Say "do X this week" with specific dollar amounts. Recognize wins ("a 17% savings rate is above the U.S. median") before pointing out gaps.
