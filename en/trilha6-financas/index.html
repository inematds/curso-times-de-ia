🚀 How to Use This Team

Orchestrator command summary — each module details the corresponding component.

How to Use

  1. Open the assistant and type /finance <comando>.
  2. Main commands:
  • /finance analyze — full financial health analysis
  • /finance quick — quick overview (60 seconds)
  • /finance budget — spending and budget analysis
  • /finance emergency — emergency fund
  • /finance debt — debt payoff strategies
  • /finance retirement — retirement outlook
  • /finance goals — financial goals plan
  • /finance portfolio — portfolio allocation
  • /finance taxes — tax optimization
  • /finance networth — net worth and milestones
  • /finance screen <critérios> — investment filter
  • /finance report-pdf — generate a financial plan in PDF

Model recommendation: a model with a large context window (64k+) to support comprehensive analyses.

Notice: educational content — not professional financial advice. Consult a licensed financial planner or accountant for specific decisions.
