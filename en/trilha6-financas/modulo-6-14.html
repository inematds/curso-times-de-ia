WARNING: For educational/informational purposes only. This does not constitute financial advice.

Objective

Compile all analyses in markdown from FINANCE-*.md files in the current working directory into a single polished PDF that a consultant, family member, or accountability partner can read from start to finish.

When to Trigger

  • The user types /finance report-pdf or /finance pdf
  • The user asks "create a PDF report," "give me a client-ready document," "export my financial plan"
  • After running /finance analyze (suggest this as the natural next step)

Prerequisites

Before generating, make sure the user has at least one analysis file in the current working directory:

  • FINANCE-ANALYSIS.md (of /finance analyze) — main input
  • FINANCE-BUDGET.md
  • FINANCE-DEBT.md
  • FINANCE-RETIREMENT.md
  • FINANCE-PORTFOLIO.md
  • FINANCE-EMERGENCY.md
  • FINANCE-NETWORTH.md
  • FINANCE-GOALS.md
  • FINANCE-COMPARE.md
  • FINANCE-SCREEN.md
  • FINANCE-FIRE.md
  • FINANCE-TAXES.md

If no files are found, ask the user to run first /finance analyze or /finance quick.

Process

Step 1: Scan Source Files

ls FINANCE-*.md

Read all files found. The Python generator script also performs its own scan; the assistant reads them beforehand to validate content quality and identify obvious gaps before generation.

Stage 2: Data Extraction

Get from the Markdown files:

  • Financial Health Composite Score (0-100) and letter grade
  • Sub-scores for each of the 5 categories (Cash Flow, Debt, Investments, Retirement, Protection)
  • Key financial data points:
  • Income / expenses / monthly surplus
  • Savings rate
  • Net worth
  • Total debt and DTI (debt-to-income ratio)
  • Months covered by the emergency fund
  • Projected retirement balance vs. what's needed
  • Asset allocation
  • Action items (ranked by priority)
  • User name / household name (if provided)
  • Generation date

Stage 3: Run the PDF Generator

Run:

Bash(python3 ~/.claude/skills/finance/scripts/generate_finance_pdf.py)

The script reads all FINANCE-*.md files from the current working directory, parses the structured sections, and builds a PDF using ReportLab.

If the script is missing or has errors, gracefully fall back to a consolidated Markdown-only report named FINANCE-PLAN.md and inform the user.

Step 4: Confirm Output

After generation:

  1. Check whether FINANCE-PLAN.pdf exists in the current working directory
  2. Report the file size and page count to the user
  3. Suggest sharing it with your financial advisor / accountant (CPA)

PDF Structure

The generator produces the following sections:

Cover Page

  • Title: "Personal Financial Plan"
  • User / household name
  • Date
  • Financial Health Composite Score Gauge (0-100 visual)
  • Letter Grade (A+ to F)
  • One-Line Signal ("Excellent — only minor optimizations")
  • Footer with Legal Disclaimer

Page 2: Executive Summary

  • Top 3 strengths
  • Top 3 priority gaps
  • This quarter’s focus (a single sentence)
  • Key numbers table:
  • Net worth
  • Monthly surplus
  • Savings rate
  • DTI
  • Emergency months

Page 3: Financial Health Score Breakdown

  • Bar chart of scores for the 5 categories
  • Each category: score / weight / what it measures / signal

Page 4: Cash Flow and Budget

  • Income vs. Expenses Chart
  • Top 5 expense categories
  • Surplus trend
  • Recommended budget adjustments

Page 5: Debt Profile

  • Total debt by type (table)
  • Average APR (Annual Percentage Rate)
  • Payoff schedule (avalanche method)
  • Interest cost on the current vs. accelerated payoff path

Page 6: Retirement Outlook

  • Years until retirement
  • Current balance vs. age benchmark
  • Projected retirement balance (3 scenarios: conservative / moderate / aggressive)
  • Balance needed for desired lifestyle
  • Gap Analysis
  • Recommended contribution rate

Page 7: Investment Portfolio

  • Pie chart of current allocation
  • Pie chart of recommended allocation
  • Drift / rebalancing needs
  • Expense Ratio Analysis
  • Diversification score

Page 8: Financial Protection

  • Emergency Fund Status
  • Insurance Coverage Matrix (health, life, disability, auto, home)
  • Estate Planning Checklist (will, beneficiaries, power of attorney, healthcare directive)
  • Priority gaps and fills

Pages 9–10: Action Plan

  • 30-Day Priorities
  • 90-Day Priorities
  • 1-Year Priorities
  • 5-Year Priorities
  • Each action includes: specific monetary amount, specific account/vehicle, due date

Final Page: Disclosures and Glossary

  • Full Legal Notice
  • Methodology Notes
  • Glossary of terms (DTI, SWR, ER, etc.)
  • "Next steps" — when to consult professionals

Visual Design Patterns

  • Color palette: Primary blue (#1f4e79), green for positive metrics, amber for warnings, red for critical issues
  • Typography: Sans-serif for headings, serif for body text
  • Charts: Clean, minimal gridlines, plain-language labels
  • Gauges: 0–100 scale with color-coded zones (red <40, amber 40–69, green 70+)
  • Tables: Alternating row shading, right-aligned numbers, currency formatting with thousands separators

Tone and Language

  • Plain English, without excessive jargon
  • Specific numbers, never vague ranges
  • Empathetic about disabilities, specific about actions
  • Confident about strengths

Error Handling

ErrorResponse
No FINANCE-*.md file found"Run /finance analyze or /finance quick first to generate the input data."
Missing Python scriptGenerate FINANCE-PLAN.md consolidated instead; tell the user how to install ReportLab
ReportLab not installedInstruct: pip3 install reportlab
Empty/malformed MarkdownSkip this section, generate the PDF without it, note it in the summary
PDF generation succeeded, but file is < 50KBProbably no data; notify the user

Customization Options

If the user wants to customize:

  • Name on the cover — Ask for the household name to display
  • Optional Sections — Allow /finance report-pdf --sections=debt,retirement to limit the scope
  • Brand — If it's for use by a consultant, allow the logo path to be injected
  • Currency — Default to USD; allow override

Validation Checklist

Before declaring success, verify:

  • [ ] The PDF file exists at the expected path
  • [ ] File size > 50KB (rough sanity check)
  • [ ] The legal disclaimer appears on the cover and final page
  • [ ] All category scores present (not "N/A" for everything)
  • [ ] At least 3 action items in the plan
