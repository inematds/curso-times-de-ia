🚀 How to Use This Team

Orchestrator command summary — each module details the corresponding component.

How to Use

  1. Open the assistant and type /trade <comando>.
  2. Main commands:
  • /trade analyze <ticker> — full stock analysis
  • /trade quick <ticker> — quick overview (60 seconds)
  • /trade fundamental <ticker> — fundamental analysis
  • /trade technical <ticker> — technical analysis
  • /trade sentiment <ticker> — sentiment and momentum
  • /trade sector <setor> — rotation and sector analysis
  • /trade options <ticker> — options strategies
  • /trade risk <ticker> — risk and sizing
  • /trade screen <critérios> — stock screener
  • /trade watchlist — manage watchlist
  • /trade earnings <ticker> — pre-earnings analysis
  • /trade compare <t1> <t2> — comparison of two assets
  • /trade portfolio — portfolio analysis
  • /trade thesis <ticker> — investment thesis
  • /trade report-pdf — generate a report in PDF

Model recommendation: a model with a large context window (64k+) to support comprehensive analyses.
