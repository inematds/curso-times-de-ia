🚀 How to Use This Team

Orchestrator command summary — each module details the corresponding component.

How to Use

  1. Open the assistant and type /crypto <comando>.
  2. Main commands:
  • /crypto analyze <token> — full token analysis
  • /crypto quick <token> — quick overview (60 seconds)
  • /crypto tokenomics <token> — tokenomics analysis
  • /crypto defi <protocolo> — DeFi protocol analysis
  • /crypto technical <token> — technical analysis
  • /crypto sentiment <token> — sentiment
  • /crypto watchlist — manage watchlist
  • /crypto compare <t1> <t2> — token comparison
  • /crypto risk <token> — risk and sizing
  • /crypto screen <critérios> — token screener
  • /crypto onchain <token> — on-chain data
  • /crypto fundamental <token> — fundamental analysis
  • /crypto narrative <tema> — narrative/cycle analysis
  • /crypto report-pdf — generate a report in PDF

Model recommendation: a model with a large context window (64k+) to support comprehensive analyses.

Notice: educational content about the crypto market — high volatility; not investment advice.
