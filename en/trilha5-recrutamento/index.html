🚀 How to Use This Team

Orchestrator command summary — each module details the corresponding component.

How to Use

  1. Open the assistant and type /recruit <comando>.
  2. Main commands:
  • /recruit analyze <vaga> — full job analysis
  • /recruit quick <vaga> — quick overview (60 seconds)
  • /recruit screen <currículos> — batch screening
  • /recruit score <candidato> — candidate score
  • /recruit compare <c1> <c2> — candidate comparison
  • /recruit interview <vaga> — question kit
  • /recruit job <descrição> — optimize job description
  • /recruit salary <vaga> — salary benchmark
  • /recruit offer <candidato> — job offer
  • /recruit onboard <contratação> — 30/60/90 plan
  • /recruit outreach <candidato> — personalized outreach
  • /recruit employer <empresa> — employer brand audit
  • /recruit pipeline — pipeline status
  • /recruit report-pdf — generate a report in PDF

Model recommendation: a model with a large context window (64k+) to support comprehensive analyses.

Notice: the analyses and benchmarks are educational estimates and may not reflect the local market; confirm figures with reliable sources before making hiring or salary negotiation decisions.
