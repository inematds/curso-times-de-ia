Routing Logic

When the user invokes /recruit <command>, route to the appropriate sub-skill.

Complete Job Analysis (/recruit analyze <role>)

This is the main command. It starts 5 parallel subagents simultaneously:

  1. Agent recruit-job → Job description quality, ATS optimization, inclusion, keyword density
  2. Agent recruit-screen → Resume screening framework, must-have vs. nice-to-have requirements, red flags
  3. Agent recruit-interview → Interview structure, behavioral and technical questions, scoring rubric
  4. Agent recruit-salary → Market salary range, geographic adjustments, total compensation benchmarks
  5. Agent recruit-employer → Employer brand competitiveness, candidate experience, retention signals

Scoring Methodology (Hiring Readiness Score 0-100):

CategoryWeightWhat It Measures
Job Description Quality20%Clarity, inclusivity, ATS optimization, candidate appeal
Screening Process20%Resume screening rigor, alignment with must-have requirements, red flag detection
Interview Framework20%Quality of questions, structure, scoring rubric, time to decision
Compensation Competitiveness20%Market alignment, total compensation, geographic accuracy
Employer Brand Strength20%Glassdoor signals, Indeed reviews, retention indicators

Hiring Readiness Composite Score = Weighted average of all 5 categories

Hiring Rating and Signal:

85-100A+Ready to hire — process is dialed in
70-84AStrong — minor refinements needed

40-54CBelow Average — losing top candidates
25-39DWeak — failed hires are likely

Quick View (/recruit quick <role>)

60-second quick job assessment. Do NOT start subagents. Instead:

  1. Ask the user: job title, location, salary range, seniority level
  2. Assess: market demand, expected time to hire, competition for candidates, salary alignment
  3. Output a quick scorecard with a hiring difficulty rating and the top 3 priorities
  4. Keep the output under 40 lines

Individual Commands

For all other commands, route to the corresponding sub-skill.

Job Opening Type Detection

Before running any analysis, detect the type of role:

  • Technical/Engineering → Focus on: technical screening, code assessment, GitHub review, take-home vs. live coding
  • Sales → Focus on: background checks, quota attainment, references, follow-up simulation
  • Executive (VP+) → Focus on: executive search, confidential outreach, board references, transition planning
  • Creative (Design/Marketing) → Focus on: portfolio review, taste assessment, brand fit, work samples
  • Operations/Administrative → Focus on: process fluency, software proficiency, attention to detail, references
  • Customer Service/Support → Focus on: communication, empathy, role-play scenarios, tone analysis
  • Healthcare/Legal/Regulated → Focus on: license verification, certification verification, compliance background checks

Output Standards

All outputs must follow these rules:

  1. Bias-Aware — Avoid language related to age, gender, ethnicity, or other protected classes
  2. Legal Compliance — Stay within EEOC guidelines; avoid prohibited questions
  3. Data-driven — Reference actual salary data and market signals
  4. Candidate-friendly — Treat candidates as people, not transactions
  5. Time-efficient — Recommendations should reduce time to hire
  6. Customer-ready — Reports should be ready to present to hiring managers without editing

File Outputs

All markdown outputs are saved in the current working directory. PDF reports generated via Bash(python3 ~/.claude/skills/recruit/scripts/generate_recruit_pdf.py).

Important: Recruiters charge $15,000-$30,000 per placement. This tool produces the analysis and documentation that justify that fee.
